# timeCheckingBot

디스코드 음성 채널에 머문 시간을 공부시간으로 기록하는 봇입니다. 서버마다 공부방 하나를 지정해서 쓰며, 누적 시간과 순위, 티어를 확인할 수 있습니다.

TypeScript, discord.js, SQLite로 만들었고 Node.js 24에서 개발·테스트했습니다.

## 실행

```sh
git clone https://github.com/jooyoungFe/timeCheckingBot.git
cd timeCheckingBot
npm ci
cp .env.example .env
```

`.env`에 아래 값을 채워주세요.

```env
DISCORD_TOKEN=
CLIENT_ID=
BOT_ADMIN_IDS=
```

`DISCORD_TOKEN`은 봇 토큰, `CLIENT_ID`는 애플리케이션 ID입니다. 둘 다 [Discord Developer Portal](https://discord.com/developers/applications)에서 확인할 수 있습니다.

`BOT_ADMIN_IDS`에는 봇 어드민으로 쓸 Discord 사용자 ID를 넣습니다. 여러 명이면 쉼표로 구분하고, 비워두면 어드민 명령어를 아무도 사용할 수 없습니다. 이 값을 바꾼 뒤에는 봇을 재시작해야 합니다.

봇을 서버에 초대하고, 공부방과 명령어를 사용할 채널을 볼 수 있게 권한을 설정해주세요. 응답을 표시할 채널에는 메시지 보내기와 링크 첨부 권한도 필요합니다.

```sh
npm run deploy
npm run build
npm start
```

`npm run deploy`는 슬래시 명령어를 Discord에 등록합니다. 처음 설정하거나 명령어 정의를 바꿨을 때 실행하면 됩니다. 봇 실행은 `npm start`가 맡습니다.

PowerShell에서 `npm.ps1` 실행이 막히면 `npm` 대신 `npm.cmd`를 쓰면 됩니다.

## 공부방 사용

서버 관리자가 먼저 `/공부방 설정`으로 음성 채널을 지정하면 됩니다. 그 채널에 들어가면 기록을 시작하고, 나가면 기록을 멈춥니다. 마이크가 꺼져 있어도 채널에 머문 시간은 기록하며, 봇 계정은 제외합니다.

| 명령어 | 용도 |
| --- | --- |
| `/공부방 설정` | 공부방으로 사용할 음성 채널 지정 |
| `/공부방 확인` | 현재 공부방 확인 |
| `/공부방 해제` | 공부방 설정 해제 |
| `/공부 시간` | 누적 공부시간과 현재 티어 조회 |
| `/공부 순위` | 현재 서버의 누적 공부시간 상위 10명 조회 |
| `/공부 진척도` | 다음 티어까지의 진행률과 남은 시간 조회 |
| `/공부 티어` | 전체 티어 기준 조회 |

`/공부방` 명령어는 서버 관리자만 사용할 수 있습니다. `/공부 시간`과 `/공부 진척도`에서 `유저`를 생략하면 본인 기록을 보여줍니다.

기록은 서버별로 따로 저장합니다. 0초는 플라스틱이며, 공부시간이 쌓이면 아이언부터 그랜드마스터까지 올라갑니다. 세부 기준은 `/공부 티어`에서 확인할 수 있습니다.

`/공부 티어` 안내는 본인에게만 보이고, 나머지 일반 명령어의 응답은 채널에 공개됩니다. 출력에는 이모지를 사용하지 않습니다.

## 어드민

어드민 명령어는 `.env`의 `BOT_ADMIN_IDS`에 등록된 사용자만 실행할 수 있습니다. 서버에서의 역할과 관계없이 봇이 참가한 서버의 기록을 관리할 수 있으며, 응답과 오류는 모두 명령어를 쓴 사람에게만 보입니다.

사용자 설치 전용 명령어라 계정에 앱을 한 번 추가해야 합니다. `npm run deploy`가 끝나면 콘솔에 나오는 **어드민 사용자 설치** 링크를 열어 본인 계정에 추가해주세요. 이후 봇이 없는 서버와 DM에서도 `/어드민`을 사용할 수 있습니다.

| 명령어 | 용도 |
| --- | --- |
| `/어드민 서버목록` | 봇이 참가한 전체 서버 조회, 페이지당 10개 |
| `/어드민 서버정보` | 서버 ID, 멤버 수, 소유자 ID, 공부방 확인 |
| `/어드민 시간조회` | 사용자의 현재 누적 공부시간 조회 |
| `/어드민 시간설정` | 누적 공부시간을 입력한 값으로 변경 |
| `/어드민 시간추가` | 기존 기록에 시간 추가 |
| `/어드민 시간차감` | 기존 기록에서 시간 차감, 최저 0초 |
| `/어드민 시간초기화` | 누적 공부시간을 0초로 초기화 |
| `/어드민 변경내역` | 시간 변경내역 조회, 페이지당 5건 |

시간 관리 명령어에는 대상 `유저id`를 입력합니다. `시간설정`, `시간추가`, `시간차감`은 `시간`이 필수이고 `분`과 `초`는 선택 사항입니다. 30분을 추가하려면 `시간:0`, `분:30`으로 입력하면 됩니다.

봇이 있는 서버에서는 `서버id`를 생략하면 현재 서버에 적용합니다. DM이나 봇이 없는 서버에서는 관리할 `서버id`를 직접 넣어야 합니다. `/어드민 서버목록`에서 확인할 수 있고, `/어드민 서버정보`는 항상 `서버id`가 필요합니다.

시간을 바꿀 때 `사유`를 함께 입력할 수 있습니다. 변경 전후 시간, 작업한 어드민 ID, 사유는 DB에 남으며 `/어드민 변경내역`에서 확인할 수 있습니다. 공부 중인 사용자의 시간을 바꾸면 변경 시점부터 계속 기록합니다.

## 데이터 보관

공부 기록, 공부방 설정, 시간 변경내역은 `data/study.db`에 저장합니다. 실행하면 필요한 폴더와 테이블을 자동으로 만듭니다.

진행 중인 공부시간은 30초마다 저장하고, 정상 종료할 때 한 번 더 저장합니다. 봇이 꺼져 있는 동안에는 시간을 기록하지 않습니다. 재시작하면 현재 공부방에 있는 사용자부터 다시 기록합니다.

서버를 옮기거나 재배포할 때는 `data` 폴더를 유지해주세요. 백업할 때는 봇을 종료한 뒤 폴더 전체를 복사하면 됩니다. `.env`와 `data`는 Git 업로드에서 제외되어 있으므로 실행 서버에서 따로 준비해야 합니다.

## 개발

```sh
npm run dev
npm test
```

`npm run dev`는 소스를 직접 실행하고, `npm test`는 빌드 후 테스트를 실행합니다. 일반 실행도 개발 실행도 Discord에 연결하므로 같은 봇을 중복으로 켜지 않도록 해주세요.
